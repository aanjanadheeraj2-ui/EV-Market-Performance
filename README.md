# ⚡ EV Market Performance

An interactive Electric Vehicle Market Performance project that combines data visualization and web development to present EV market insights through a Tableau Dashboard and Story.

## 🌐 Project Links

- **Live Website:** [EV Market Performance](https://ev-market-performance.onrender.com)
- **Project Demonstration Video:** [Watch Demo Video](https://drive.google.com/file/d/1sgE--LV4atRSZhFdNsD_ebACu_LFwsam/view?usp=drive_link)

## 📌 Project Overview

The EV Market Performance project focuses on exploring electric vehicle market data through interactive data visualizations.

The project uses Tableau Public to create a dashboard and a story that help users understand the available market information in a visual and organized format.

A Flask-based web application integrates these Tableau visualizations into a single website, making the project accessible through a web browser.

## 🎯 Project Objectives

- Explore electric vehicle market data.
- Present market information through data visualizations.
- Create an interactive Tableau Dashboard.
- Develop a Tableau Story to present the analysis.
- Integrate Tableau visualizations into a web application.
- Deploy the application online for public access.

## ✨ Key Features

- **Interactive Tableau Dashboard:** Visual representation of EV market data.
- **Tableau Story:** Structured presentation of the visual analysis.
- **Web Integration:** Dashboard and Story embedded into the website.
- **Responsive Design:** Website designed for convenient browser access.
- **Online Deployment:** Publicly accessible application hosted on Render.

## ⚙️ Run the Project Locally

Follow these steps to run the application on your computer.

### 1. Clone the Repository

```bash
git clone https://github.com/aanjanadheeraja2-ui/EV-Market-Performance.git
```

### 2. Navigate to the Project Folder

```bash
cd EV-Market-Performance
```

### 3. Create a Virtual Environment

```bash
python3 -m venv venv
```

### 4. Activate the Virtual Environment

For macOS/Linux:

```bash
source venv/bin/activate
```

### 5. Install Dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the Application

```bash
python app.py
```

### 7. Open in Your Browser

Visit:

```text
http://127.0.0.1:5000
```
